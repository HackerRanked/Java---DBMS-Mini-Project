PHASE 1 Questions:
Five viva topics
1. How the checked exception subclasses inherit from LfrlmsException, and how DataAccessException preserves an SQLException cause.
2. How Customer and Contract use abstract classes and how their subclasses call super(...).
3. How the ArrayList<Customer> and ArrayList<Billable> demonstrate polymorphism.
4. Why money uses BigDecimal, dates use java.time, and statuses use string constants instead of Java enums.
5. How DBConnection loads local properties and returns a fresh connection, while QueryLog and LookupCache use collections.

Phase 2a Questions:
Five viva points
1. How QueryBuilder keeps values in placeholders, escapes %, _, and ! for LIKE, and restricts sorting to a whitelist.
2. How AbstractDao closes JDBC resources, obtains fresh connections, records queries, and translates SQL errors—including error 1451.
3. Why paginated searches use LIMIT/OFFSET and a count query with the same filters.
4. Why customer parent rows and subtype rows have separate DAOs, while services will handle their transaction together.
5. How CallableStatement invokes stored procedures and functions, and how QueryLog records SQL, parameters, duration, and row counts.

Phase 2b Questions:
Five viva topics
1. How JDBC transactions use setAutoCommit(false), commit(), and rollback().
2. Why SELECT ... FOR UPDATE protects a vehicle during rental operations.
3. How DAO methods reuse a caller-owned connection without closing it.
4. How the shared date converters preserve Connector/J LocalDate and LocalDateTime values.
5. How the tests verify rollback by checking that no rental or customer parent row remains.
